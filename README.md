TCG Price Tracker

Aplicación web para monitorizar los precios de cartas de juegos de cartas coleccionables (TCG), consultar su evolución histórica y recibir alertas cuando los precios suban o bajen.

Objetivos
Buscar cartas de diferentes juegos TCG.
Añadir cartas a una lista personal de seguimiento.
Consultar el historial y la evolución de los precios.
Configurar alertas cuando una carta alcance un precio determinado.
Consultar las variaciones de precio de las cartas monitorizadas.
